# Канон продуктов PerfOps

Источник истины: [`src/lib/perfops-v4-data.ts`](../../src/lib/perfops-v4-data.ts) (`products[]`). Все тексты на страницах продуктов, в карточках на главной и в каталоге берутся отсюда. Менять тексты можно только через этот файл.

## Форматы результата

Закрытый список из трёх форматов (`ResultFormat`):

| ID | Подпись в UI |
| --- | --- |
| `excel` | Excel-файл |
| `dashboard-link` | Ссылка на дашборд |
| `analytics-report` | Аналитический отчёт |

## Продукты

### 1. Конструктор дашбордов (`dashboard-builder`)

- **Короткое описание:** Сводный дашборд по выгрузкам кампаний с разбивкой по периодам.
- **Результат:** Ссылка на дашборд.
- **Шаги:** Источник → Объединение → Проверка → Запуск → Результат.
- **Источники:** загрузка файла, подключённый аккаунт, источник из Библиотеки.
- **Подключения:** Яндекс Директ, Google Ads, Google Sheets.
- **Файлы:** `.xlsx`, `.csv`.
- **Особенности:** поддерживает второй источник и объединение, есть демо-дашборд.

### 2. Анализ кампаний (`campaign-analysis`)

- **Короткое описание:** Аналитический отчёт с изменениями, аномалиями и сегментами внимания.
- **Результат:** Аналитический отчёт.
- **Шаги:** Источник → Метрики и фокус → Проверка → Запуск → Результат.
- **Источники:** загрузка, подключение, Библиотека.
- **Подключения:** Яндекс Директ, Google Ads.
- **Файлы:** `.xlsx`, `.csv`.
- **Особенности:** один источник, без объединения.

### 3. Сбор и обработка семантики (`semantics-generator`)

- **Короткое описание:** Excel-файл с дедуплицированным семантическим ядром и кластерами.
- **Результат:** Excel-файл.
- **Шаги:** Сценарий → Источник → Параметры → Проверка → Запуск → Результат.
- **Источники:** текстовая тема, URL, загрузка файла, Библиотека.
- **Подключения:** —
- **Файлы:** `.xlsx`, `.csv`, `.txt`.
- **Сценарии (на шаге «Сценарий»):** Консервативный · Сбалансированный · Охватный · Исследование · Кластеризация. Слово «режим» в этом продукте не используем.

### 4. Кросс-минусовка (`cross-minus`)

- **Короткое описание:** Excel-файл с готовыми списками кросс-минус-слов по группам объявлений.
- **Результат:** Excel-файл.
- **Шаги:** Источник → Проверка → Запуск → Результат.
- **Источники:** загрузка, подключение, Библиотека.
- **Подключения:** Яндекс Директ.
- **Файлы:** `.xlsx`, `.csv`.

### 5. BD Optimization (`bd-optimization`)

- **Короткое описание:** Excel-файл для снижения каннибализации и атрибуцированных потерь.
- **Результат:** Excel-файл.
- **Шаги:** Источник → Параметры → Проверка → Запуск → Результат.
- **Источники:** загрузка, подключение, Библиотека.
- **Подключения:** Яндекс Директ, Google Ads.
- **Файлы:** `.xlsx`, `.csv`.
- **Важно:** название не переводим. Не использовать «Оптимизация ставок и бюджетов» в UI.

- «Оптимизация ставок и бюджетов» (вместо «BD Optimization»)
