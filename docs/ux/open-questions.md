# Открытые вопросы

Эти вопросы намеренно **не решаем** на этапе Lovable-прототипа. Они зафиксированы, чтобы не «уходить» в них спонтанно и не размывать UI-контракт.

## Flow и продукты

- **Семантика → сценарий «Кластеризация».** Нужно ли отдельное визуальное ответвление flow (свои поля параметров) или достаточно текущего общего шага «Параметры»? — решение позже.
- **Поведение «Объединение» при ≥3 источниках.** Сейчас контракт допускает максимум 2 источника. Расширение — отдельная задача.
- **Перепрогон и история запусков.** В UI-контракте только «текущий результат». Версионирование, журнал запусков, diff между прогонами — не входят в этот этап.
- **Сценарий ошибки во время «Запуска».** Сейчас в справочнике состояний покрыты ошибки сохранения результата. Полная карта ошибок исполнения (таймаут, частичный результат, ошибка источника во время прогона) — отдельная итерация.

## Библиотека

- **Реальная пагинация и «Показать ещё».** Сейчас Библиотека — статичный mock. Бесконечная подгрузка/пагинация — после переноса в production.
- **Версии источников и результатов в Библиотеке.** Контракт сейчас не описывает версионирование записей.
- **Права доступа к записям Библиотеки.** Шеринг, приватность, командный доступ — не на этом этапе.

## Подключения

- **OAuth-флоу для каждого типа подключения.** В прототипе только UI-обвязка и моки аккаунтов. Реальные шаги авторизации с провайдерами — production.
- **Состояние «Требуется действие».** Что именно показываем пользователю и какие шаги починки — уточняем по каждой системе отдельно.

## Визуал и доступность

- **Контраст бейджей.** Нужен повторный аудит контраста для всех тонов (`info`, `warning`, `success`, `destructive`, `processing`) на тёмной и светлой теме.
- **Тёмная тема.** Токены готовы, но финальная проходка по всем экранам в тёмной теме не делалась.
- **Адаптив < 768px.** Прототип проектируется под десктоп. Мобильный layout — отдельная итерация.
- **Локализация.** Все тексты сейчас только на русском. Архитектура i18n — позже.

## Производственные интеграции

- Реальные API endpoints, секреты, авторизация пользователей — **вне этого репозитория** и вне UI-контракта.
- Аналитика и события продукта (что трекаем при создании проекта, переходе по шагам, открытии результата) — отдельный документ, не в этом этапе.
