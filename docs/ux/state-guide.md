# Справочник состояний

Живой справочник: [`/v4/flow-states`](http://localhost:3000/v4/flow-states) → [`src/routes/v4.flow-states.tsx`](../../src/routes/v4.flow-states.tsx). Этот документ — текстовое зеркало; при расхождении источник истины — код.

> Технические тональности (`info`, `warning`, `success`, `blocked`, `processing`, `neutral`) — внутренний справочник для разработчиков и дизайнеров. В пользовательский интерфейс **названия тональностей не выводятся**.

## Состояния

| Состояние | Tone | Когда показываем |
| --- | --- | --- |
| Источник не выбран | neutral | До добавления источника на шаге «Источник». |
| Идёт загрузка | info | Файл передаётся на сервер, виден прогресс. |
| Источник выбран | info | Источник добавлен и готов к проверке. |
| Проверка | info | Платформа проверяет источник и параметры. |
| Источник принят | success | Источник прошёл проверку, можно запускать. |
| Предупреждение | warning | Замечания не блокируют запуск, можно продолжать или вернуться. |
| Блокировка | blocked | Запуск невозможен — несоответствие обязательным требованиям. |
| Идёт обработка | processing | Продукт выполняет работу, можно вернуться позже. |
| Результат готов | success | Результат создан и сохранён в Библиотеке. |
| Результат готов, но не сохранён в Библиотеке | warning | Локальная копия есть, в Библиотеке — нет. Можно повторить сохранение или скачать. |
| Повторное сохранение | processing | Повторная попытка сохранения в Библиотеке. |
| Сохранить результат не удалось | blocked | Все попытки исчерпаны — скачать локальную копию или связаться с поддержкой. |

## Правила

- Слово «деградирован» **не используем**.
- Не вводим новые тональности или состояния без явного требования.
- В пользовательских текстах не пишем «регистрация результата» — у нас «сохранён в Библиотеке».
